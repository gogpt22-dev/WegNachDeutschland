# Weg nach Deutschland 🇩🇪 — Android App
مشروع Android جاهز للبناء، يحوّل خطة HTML إلى تطبيق WebView.
- حفظ الاسم والتقدم والملاحظات عبر LocalStorage
- قفل الأيام والمستويات بالتتابع
- روابط YouTube تعمل من التطبيق
- يعمل بوضع Portrait ومناسب للموبايل

لإخراج APK: افتح المشروع في Android Studio ثم Build > Build APK(s).
